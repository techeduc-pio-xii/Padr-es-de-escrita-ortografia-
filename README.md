# Trilha da Ortografia – R, RR e Q

Jogo educativo digital sobre ortografia (uso de R, RR e Q) para o Ensino Fundamental.

## Como usar
Abra o `index.html` no navegador ou publique pelo GitHub Pages
(Settings → Pages → Branch `main` → pasta `/root`).

## Estrutura
- `index.html` – estrutura da página
- `style.css` – estilos
- `script.js` – lógica do jogo
